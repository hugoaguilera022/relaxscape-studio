# AutoTube Studio

Aplicación independiente para automatizar el flujo de creación de vídeos de YouTube.

## Flujo
1. Descubrir tema con IA.
2. Investigar el tema.
3. Crear estructura.
4. Escribir guion.
5. Generar narración.
6. Generar visuales 16:9.
7. Montar vídeo 1920x1080.
8. Preparar título, descripción y etiquetas.
9. Conectar YouTube y subir.
10. Endpoint diario para automatización.

## Variables
- GEMINI_API_KEY
- GEMINI_TEXT_MODEL
- HF_TOKEN
- HF_TTS_MODEL
- YOUTUBE_CLIENT_ID
- YOUTUBE_CLIENT_SECRET
- YOUTUBE_REDIRECT_URI
- YOUTUBE_REFRESH_TOKEN
- AUTOMATION_SECRET
- AUTOMATION_NICHE
- AUTOMATION_MINUTES

No guardar claves dentro del repositorio.

## Formato
Los vídeos generados son horizontales 16:9, pensados para YouTube.
